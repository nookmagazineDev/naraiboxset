## 1. ภาพรวมระบบ

- ระบบ POS ทำงานผ่าน **เว็บเบราว์เซอร์** (แนะนำ Google Chrome) บนแท็บเล็ตหรือคอมพิวเตอร์
- ข้อมูลทั้งหมด (เมนู, หมวดหมู่, พนักงาน, ออเดอร์, ยอดขาย, สต็อก) เก็บไว้ใน **Google Sheet** ผ่าน Google Apps Script
- ระบบจะ **ดึงข้อมูลล่าสุดอัตโนมัติทุก 10 วินาที** — ถ้าแอดมินแก้เมนู/ราคา เครื่องหน้าร้านจะอัปเดตเองภายในไม่กี่วินาที
- รองรับ **หลายสาขา** — แต่ละสาขามีบัญชีของตัวเอง เลขบิลนับแยกกัน และรายงานกรองตามสาขาได้
- รองรับ **2 ภาษา** ไทย / อังกฤษ (กดปุ่ม 🌐 TH/EN มุมขวาบน)

### ลำดับการทำงานหลัก

```
เข้าสู่ระบบ → เลือกเมนู → (เลือกตัวเลือก) → ตะกร้า → ส่งรายการอาหาร
     → หน้าสรุปบิล (โต๊ะ) → ชำระเงิน → เลือกส่วนลด → เลือกวิธีจ่าย
     → พิมพ์ใบเสร็จ → กด "เสร็จสิ้น" (บันทึกบิลขึ้นระบบ)
```

## 2. สิทธิ์ผู้ใช้งาน 3 ระดับ

| สิทธิ์ | ใช้หน้าร้าน (สั่ง/เช็คบิล) | เข้าหลังบ้าน | หน้าหลังบ้านที่เข้าได้ |
|---|---|---|---|
| **พนักงานทั่วไป** | ✅ | ❌ | — |
| **💳 แคชเชียร์** | ✅ | ✅ (บางหน้า) | แดชบอร์ด, จัดการเมนู, หมวดหมู่, ส่วนลด, สต็อกวัตถุดิบ (ไม่เห็นต้นทุน) |
| **👑 แอดมิน** | ✅ | ✅ (ทุกหน้า) | ทุกหน้า รวมถึง พนักงาน, ปริ้นเตอร์, BOM, ตั้งค่าร้าน, รายงาน, หน้าจอครัว |

นอกจากนี้แต่ละบัญชีมีตัวเลือก **"สิทธิ์ชำระเงิน"** (อนุญาต / ไม่อนุญาต)
ถ้าตั้งเป็น **ไม่อนุญาต** ปุ่ม "ชำระเงิน" จะเป็นสีเทา กดแล้วขึ้นว่า *"ไม่มีสิทธิ์ในการชำระเงิน"* (แอดมินชำระได้เสมอ)

> 📌 ปุ่ม **⚙️ จัดการหลังบ้าน** บนหน้าร้าน จะแสดงเฉพาะแอดมิน — ส่วนแคชเชียร์เข้าหลังบ้านได้ทางลิงก์ `/admin`

## 3. การเข้าสู่ระบบ / ออกจากระบบ

### 3.1 เข้าสู่ระบบ

1. เปิดโปรแกรม POS → จะเห็นหน้า **"เข้าสู่ระบบ — เลือกสาขาของคุณ"**
2. กดเลือก **ชื่อสาขา** ของตัวเอง
3. พิมพ์ **รหัสผ่านของสาขา** → กด **เข้าสู่ระบบ** (หรือกด Enter)
4. เข้าสู่ระบบสำเร็จ → ระบบพาไปที่ **หน้าสั่งอาหาร** ทันที (โต๊ะเริ่มต้น = โต๊ะ 1)

> - รหัสผิด จะขึ้น *"รหัสผ่านไม่ถูกต้อง"* ให้พิมพ์ใหม่
> - กดลูกศรย้อนกลับเพื่อเปลี่ยนสาขาที่เลือก
> - รหัสที่ขึ้นต้นด้วยเลข 0 (เช่น `0123`) ใช้งานได้ตามปกติ

### 3.2 กรณีโหลดรายชื่อสาขาไม่ขึ้น

- ช่วง 5 วินาทีแรกจะขึ้น *"กำลังโหลดรายชื่อพนักงาน..."*
- ถ้าเกิน 5 วินาทีแล้วยังไม่ได้ จะขึ้น **"เชื่อมต่อฐานข้อมูลไม่ได้"** พร้อมปุ่ม:
  - **ลองเชื่อมต่อใหม่** — เช็กอินเทอร์เน็ตแล้วกดปุ่มนี้
  - **เข้าในฐานะแอดมิน (ชั่วคราว)** — ใช้ในกรณีฉุกเฉินเท่านั้น (ใช้งานในชื่อสาขา `admin`)

### 3.3 ออกจากระบบ

- กดปุ่มสีแดง **ออกจากระบบ (ชื่อสาขา)** มุมขวาบน → กดยืนยัน
- ระบบ **ไม่จำการล็อกอิน**: ปิด/รีเฟรชหน้าเว็บ ต้องล็อกอินใหม่ทุกครั้ง
- ⏰ **ล็อกเอาต์อัตโนมัติ** เมื่ออยู่ในระบบครบ **8 ชั่วโมง** (จะมีแถบแดงแจ้งเตือน ให้ล็อกอินใหม่)

## 4. หน้าจอหลัก (หน้าสั่งอาหาร)

### 4.1 แถบด้านบน (Header) — จากซ้ายไปขวา

| ส่วน | การใช้งาน |
|---|---|
| โลโก้ + **NaraiBoxset** + **โต๊ะ X** | แสดงโต๊ะที่กำลังสั่งอยู่ |
| 👤 **ประเภทลูกค้า** (ดรอปดาวน์) | เลือกระดับราคา เช่น *ปกติ*, *พนักงาน*, *เดลิเวอรี่* ฯลฯ — ราคาทุกเมนูบนจอจะเปลี่ยนตามทันที |
| **ชื่อลูกค้า (ถ้ามี)** | พิมพ์ชื่อลูกค้า (ไม่บังคับ) — ชื่อจะติดไปกับทุกรายการที่สั่งหลังจากนี้ |
| 🧾 **สรุปบิล** | ไปหน้าสรุปบิลของโต๊ะ (ดูรายการ / ย้ายโต๊ะ / ชำระเงิน) |
| 🗑️ **ทิ้ง (Waste)** | บันทึกวัตถุดิบ/อาหารที่ทิ้ง |
| 📊 **สรุปยอดขายวันนี้** | ดูยอดขายของวันนี้ |
| 📅 **สรุปยอดขายระหว่างวัน** | ดูยอดขายตามช่วงวันที่ (ค่าเริ่มต้น 7 วันล่าสุด) |
| 🔄 **รีเฟรช** | ดึงข้อมูลล่าสุดจากระบบทันที (ปกติดึงเองทุก 10 วิ) |
| ⚙️ **จัดการหลังบ้าน** | (เฉพาะแอดมิน) เข้าหน้าตั้งค่า |
| 🌐 **TH / EN** | สลับภาษา |
| **ออกจากระบบ** | ออกจากระบบ |
| 🛍️ **ปุ่มตะกร้า** | แสดงจำนวนรายการและยอดรวมในตะกร้า กดเพื่อเปิดตะกร้า |

### 4.2 แถบหมวดหมู่ (ด้านซ้าย)

- แสดงหมวดหมู่ทั้งหมด พร้อมไอคอนและ **จำนวนรายการ** ในหมวด
- กดหมวดหมู่เพื่อแสดงเมนูในหมวดนั้น
- หมวดที่ไม่มีเมนูเปิดใช้งานเลย จะถูกซ่อนอัตโนมัติ
- เมนู 1 รายการอาจอยู่ได้หลายหมวด (ตั้งค่าในหลังบ้าน)

### 4.3 การ์ดเมนู (ตรงกลาง)

- แต่ละการ์ดแสดง รูป, ชื่อเมนู, รายละเอียด และ **ราคาตามประเภทลูกค้าที่เลือกอยู่**
- เมนูที่อยู่ในตะกร้าแล้วจะมีตัวเลขจำนวน และปุ่ม **–** / **+** บนการ์ด
  - **+** = สั่งเพิ่มอีก 1
  - **–** = ลดจำนวนรายการล่าสุดของเมนูนั้นลง 1 (ถ้าเหลือ 1 จะลบออกจากตะกร้า)

## 5. การสั่งอาหาร

### 5.1 เลือกประเภทลูกค้าก่อนสั่ง (สำคัญ)

ราคาของเมนูถูกกำหนดจาก **"ประเภทลูกค้า"** ที่เลือกไว้ด้านบน **ณ ตอนที่กดเพิ่มเมนูลงตะกร้า**

- ถ้าเลือกประเภทที่เมนูนั้นไม่มีราคาไว้ → ระบบใช้ **ราคาปกติ** แทน
- ถ้าจะสั่งหลายประเภทราคาในบิลเดียว ให้เปลี่ยนประเภทลูกค้าก่อนกดเมนูแต่ละรายการ
- ชื่อประเภทราคาจะแสดงต่อท้ายรายการในบิล (เช่น "พนักงาน")

### 5.2 เมนูที่ไม่มีตัวเลือก

กดการ์ดเมนู → **เพิ่มลงตะกร้าทันที** และเปิดหน้าตะกร้าขึ้นมาให้ดู

### 5.3 เมนูที่มีตัวเลือก (Popup / Wizard)

บางเมนูตั้งให้มีขั้นตอนเลือก เช่น เลือกเนื้อสัตว์, ท็อปปิ้ง, เครื่องดื่มในเซ็ต (สูงสุด 6 ขั้นตอน)

1. กดการ์ดเมนู → หน้าต่างเลือกตัวเลือกจะขึ้น ด้านบนบอก **"ขั้นตอนที่ 1/N"**
2. ในแต่ละขั้นตอน:
   - กดตัวเลือกเพื่อเพิ่ม (กดซ้ำเพื่อเพิ่มจำนวน ถ้าเมนูอนุญาตให้เลือกซ้ำ)
   - กดปุ่ม **–** บนตัวเลือกเพื่อลดจำนวน
   - กด **ไม่รับ (ข้าม)** ถ้าไม่ต้องการตัวเลือกในขั้นนี้
   - ถ้าขึ้นว่า *"ต้องเลือกอย่างน้อย X รายการ"* ต้องเลือกให้ครบก่อนจึงจะไปต่อได้
   - บางขั้นจำกัดจำนวนสูงสุด — กดเพิ่มเกินจะไม่ขึ้น
3. บางเมนูมีขั้นตอน **การรับประทาน**: เลือก **ทานที่ร้าน** หรือ **ห่อกลับบ้าน**
4. กด **ถัดไป (ยอดรวมชั่วคราว: ฿...)** เพื่อไปขั้นต่อไป / **ย้อนกลับ** เพื่อแก้
5. ขั้นสุดท้ายกด **ยืนยันและเพิ่ม (฿...)** → รายการเข้าตะกร้า

> 💡 ตัวเลือกที่มีราคา จะบวกเพิ่มเข้าราคาเมนูอัตโนมัติ ส่วนตัวเลือกที่ตั้งเป็น "ฟรี" จะไม่บวกราคา
> 💡 บางเมนูมี **เมนูแถมอัตโนมัติ (Bundled)** — ระบบจะใส่ของแถมให้ราคา ฿0 โดยไม่ต้องกดเอง

## 6. ตะกร้าสินค้า และการส่งรายการอาหาร

เปิดตะกร้าโดยกดปุ่ม 🛍️ มุมขวาบน (หรือเปิดขึ้นเองหลังเพิ่มเมนู)

### 6.1 สิ่งที่ทำได้ในตะกร้า

| การทำงาน | วิธีทำ |
|---|---|
| ดูรายละเอียด | แต่ละรายการแสดง ชื่อลูกค้า, ตัวเลือก (รวมของซ้ำ เช่น "Leo ขวด ×12"), การรับประทาน |
| ใส่หมายเหตุ | พิมพ์ในช่อง **📝 หมายเหตุ** เช่น *ไม่ใส่ผัก, เผ็ดน้อย* |
| เพิ่ม/ลดจำนวน | กด **+** / **–** (ต่ำสุด 1) |
| ลบรายการ | กดไอคอนถังขยะ → กดยืนยัน |
| ดูยอด | ยอดอาหาร, เซอร์วิสชาร์จ, VAT (ถ้าเปิดใช้) และ **รวมทั้งสิ้น** |

### 6.2 ปุ่มด้านล่าง

- **➕ สั่งเพิ่ม** — ปิดตะกร้า กลับไปเลือกเมนูต่อ
- **✅ ส่งรายการอาหาร** — ส่งรายการทั้งหมดในตะกร้าไปยังโต๊ะ
  - ตะกร้าจะถูกล้าง
  - ระบบพาไปหน้า **สรุปบิล** ของโต๊ะนั้นทันที
  - รายการถูกบันทึกขึ้นระบบ (ชีต TableOrders) ภายในไม่กี่วินาที

> ⚠️ รายการที่ยังอยู่ในตะกร้า **ยังไม่ถูกบันทึก** — ต้องกด "ส่งรายการอาหาร" ก่อนเสมอ

## 7. หน้าสรุปบิล (จัดการโต๊ะ)

เข้าได้จากปุ่ม **🧾 สรุปบิล** หรือหลังจากกดส่งรายการอาหาร

### 7.1 ส่วนประกอบของหน้า

- หัวข้อ **โต๊ะ X** + จำนวนลูกค้า **(N ท่าน)** — กดที่ตัวเลขเพื่อ **แก้ไขจำนวนลูกค้า** แล้วกดบันทึก
- ปุ่ม **ย้ายโต๊ะ / รวมโต๊ะ / แยกโต๊ะ**
- ช่อง **ประเภทลูกค้า** และ **ชื่อลูกค้า** (เชื่อมกับหน้าสั่งอาหาร)
- รายการอาหารทั้งหมดของโต๊ะ — แต่ละรายการแสดง จำนวน, ชื่อ, ตัวเลือก/หมายเหตุ, เวลาสั่ง 🕒, ราคารวม
- ปุ่ม 🗑️ ข้างแต่ละรายการ — **ลบรายการนั้นออกจากโต๊ะ** (ลบทันที ไม่มีถามยืนยัน — กดอย่างระวัง)
- สรุปยอด: ยอดอาหาร, เซอร์วิสชาร์จ, VAT, **ยอดรวม**
- ปุ่มด้านล่าง: **สั่งเพิ่ม** และ **ชำระเงิน ฿...**

### 7.2 ย้ายโต๊ะ / รวมโต๊ะ / แยกโต๊ะ

| คำสั่ง | ใช้เมื่อ |
|---|---|
| **ย้ายโต๊ะ** | ลูกค้าย้ายไปนั่งโต๊ะว่าง |
| **รวมโต๊ะ** | รวมบิลเข้ากับโต๊ะที่มีลูกค้าอยู่แล้ว |
| **แยกโต๊ะ** | แยกบางรายการไปอีกโต๊ะ (เช่น แยกจ่าย) |

ขั้นตอน:

1. (ถ้าต้องการทำเฉพาะบางรายการ) ติ๊กเลือกรายการที่ต้องการ — หรือกด **เลือกทั้งหมด**
   - **ถ้าไม่ได้ติ๊กอะไรเลย = ดำเนินการกับทั้งโต๊ะ**
2. กดปุ่ม ย้าย / รวม / แยก
3. พิมพ์ **เบอร์โต๊ะเป้าหมาย** → กด **ถัดไป**
4. ระบบถามยืนยันอีกครั้ง เช่น *"ย้ายโต๊ะ ทั้งโต๊ะ จากโต๊ะ 1 ไปโต๊ะ 5 ?"* → กด **ยืนยัน**
5. ระบบพาไปหน้าสรุปบิลของโต๊ะปลายทาง

> 💡 เมื่อย้ายทั้งโต๊ะ จำนวนลูกค้าจะย้ายตามไปด้วย

> 📌 **การเปิดโต๊ะอื่น:** ระบบเริ่มที่ **โต๊ะ 1** เสมอ หากต้องการใช้หลายโต๊ะ ให้ส่งรายการอาหารเข้าโต๊ะ 1 แล้วใช้ **ย้ายโต๊ะ** ไปเบอร์ที่ต้องการ

## 8. การชำระเงิน (เช็คบิล)

ในหน้าสรุปบิล กดปุ่ม **ชำระเงิน ฿...** แล้วทำตามขั้นตอน:

### ขั้นที่ 1 — สรุปบิล

ตรวจสอบรายการและยอดรวม → กด **ดำเนินการชำระเงิน ฿...**

### ขั้นที่ 2 — เลือกส่วนลด

- เลือกส่วนลดจากรายการ (แสดงมูลค่าที่ลด และ **ยอดสุทธิ** ให้ดูก่อน)
- กดซ้ำที่ส่วนลดเดิมเพื่อยกเลิก หรือกด **❌ ไม่ใช้ส่วนลด**
- กด **ชำระเงิน ฿...** เพื่อไปขั้นต่อไป

> **วิธีคำนวณยอด:**
> 1. ยอดอาหาร − ส่วนลด
> 2. \+ เซอร์วิสชาร์จ (คิดจากยอดหลังหักส่วนลด)
> 3. \+ VAT (คิดจากยอดหลังหักส่วนลด + เซอร์วิสชาร์จ)
> 4. = **รวมทั้งสิ้น**

### ขั้นที่ 3 — เลือกวิธีชำระเงิน

#### 💵 เงินสด
1. พิมพ์ **รับเงินมา (บาท)** หรือกดปุ่มจำนวนเงินลัด (เช่น 100 / 500 / 1000)
2. ระบบคำนวณ **เงินทอน** ให้อัตโนมัติ (ถ้าเงินไม่พอจะขึ้นสีแดง "ไม่พอ!" และกดยืนยันไม่ได้)
3. กด **ยืนยันรับเงิน**

#### 📱 เงินโอน / QR Code
1. ระบบสร้าง **QR พร้อมยอดเงิน** ให้ลูกค้าสแกนอัตโนมัติ (รองรับทุกแอปธนาคาร)
   - แสดงชื่อร้าน/บัญชี และเลขบิล
2. ตรวจสอบว่าเงินเข้าแล้ว → กด **ยืนยันรับเงินโอนแล้ว**
3. หน้า **แนบสลิปการโอน**:
   - กด **📷 ถ่ายรูป** หรือ **อัปโหลดไฟล์** → กด **บันทึกสลิปและเสร็จสิ้น**
   - หรือกด **ข้ามไปก่อน (ไม่แนบสลิป)**

#### 💳 บัตรเครดิต / เดบิต
1. รูดบัตรที่เครื่อง **EDC** ที่เคาน์เตอร์
2. เมื่อรูดสำเร็จ กด **ยืนยันรับชำระบัตรแล้ว**

#### 🔀 แยกจ่าย (หลายวิธี)
1. กรอกจำนวนเงินในช่อง **เงินสด / เงินโอน-QR / บัตรเครดิต**
2. กดปุ่ม **ที่เหลือ** ข้างช่องใดก็ได้ เพื่อเติมยอดที่ยังขาดลงช่องนั้นอัตโนมัติ
3. ดูแถบสถานะ: **ยังขาด / เกิน / ครบพอดี ✓**
4. ต้องกรอกอย่างน้อย **2 ประเภท** และยอดต้อง **ครบพอดี** จึงจะกด **ยืนยันการแยกจ่าย** ได้
5. ถ้ามีส่วนที่เป็นเงินโอน ระบบจะให้แนบสลิปต่อ

### ขั้นที่ 4 — ชำระเงินสำเร็จ + ใบเสร็จ

- หน้าจอแสดง **พรีวิวใบเสร็จ (80mm)**: เลขบิล, โต๊ะ, วันที่, วิธีชำระ, รายการ, ส่วนลด, ค่าบริการ, VAT, รวมทั้งสิ้น
- กด **🖨️ พิมพ์ใบเสร็จ** เพื่อพิมพ์
- กด **✅ เสร็จสิ้น** เพื่อจบการขาย

> ⚠️ **สำคัญมาก:** บิลจะถูกบันทึกขึ้นระบบ **ตอนกด "เสร็จสิ้น"** เท่านั้น
> ถ้าปิดหน้าต่างก่อนกด "เสร็จสิ้น" บิลจะยังไม่ถูกบันทึก และโต๊ะยังไม่ถูกเคลียร์

เมื่อกด "เสร็จสิ้น" ระบบจะ:
1. ออกเลขบิลแบบ **รหัสสาขา-#เลขลำดับ** (เช่น `XUM-#015`) — แต่ละสาขานับเลขของตัวเอง
2. บันทึกบิลและข้อมูลการชำระเงินลงระบบ
3. เคลียร์รายการของโต๊ะนั้น และลบจำนวนลูกค้า
4. ตัดสต็อกวัตถุดิบตามสูตร (BOM) อัตโนมัติ
5. กลับไปหน้าสั่งอาหาร (โต๊ะ 1)

## 9. บันทึกของทิ้ง (Waste)

ใช้บันทึกอาหาร/เครื่องดื่ม/วัตถุดิบที่เสีย หมดอายุ ทำตก หรือลูกค้าคืน

1. หน้าสั่งอาหาร กด **🗑️ ทิ้ง (Waste)**
2. ตรวจสอบช่อง **สาขา** (ระบบใส่ชื่อสาขาที่ล็อกอินให้อัตโนมัติ)
3. **เลือกไอเทมที่ทิ้ง** จากรายการเมนู
4. กรอก **จำนวนที่ทิ้ง** และเลือกหน่วย (จาน, แก้ว, ขวด, ชิ้น, ถ้วย, กรัม ฯลฯ)
5. กรอก **หมายเหตุ / สาเหตุ** เช่น *หมดอายุ, ทำตก, ลูกค้าคืน*
6. กด **บันทึกการทิ้ง** → ขึ้น *"✅ บันทึกสำเร็จ"*
7. ด้านล่างแสดง **ประวัติการทิ้ง** (กด รีเฟรช เพื่ออัปเดต) — กด **กลับ** เพื่อกลับหน้าสั่งอาหาร

## 10. สรุปยอดขาย

เปิดจากปุ่ม **📊 สรุปยอดขายวันนี้** หรือ **📅 สรุปยอดขายระหว่างวัน**

### 10.1 เลือกช่วงเวลา

- ปุ่มลัด: **วันนี้ / เมื่อวาน / 7 วันล่าสุด / 30 วันล่าสุด / เดือนนี้**
- หรือเลือกวัน **เริ่มต้น (From)** – **สิ้นสุด (To)** เอง แล้วกด **ดึงรายงาน**
- **ตัวกรองสาขา:** แอดมินเลือกดูได้ทุกสาขา / รายสาขา — บัญชีสาขาทั่วไปเห็นเฉพาะของสาขาตัวเอง

### 10.2 ข้อมูลที่แสดง

- 💰 **ยอดขายทั้งหมด**
- 🧾 **จำนวนบิลทั้งหมด** — กดเพื่อดู **รายละเอียดบิลทั้งหมด** (ค้นหาด้วยเลขบิล, โต๊ะ, วิธีชำระเงิน ได้)
- **ช่องทางการชำระเงิน**: เงินสด / เงินโอน-QR / บัตรเครดิต
- **ยอดขายรวมตามเมนู** (รวมของในเซ็ตและป๊อปอัป — แสดงป้าย [เสริม/เซ็ต]) — กดชื่อเมนูเพื่อดูรายละเอียดเชิงลึก
- **รายการทิ้ง (Waste)** ในช่วงเวลาเดียวกัน

### 10.3 ส่งออกข้อมูล

- **💾 รูปภาพ (PNG)** — บันทึกหน้าสรุปเป็นรูป (เหมาะส่งไลน์กลุ่ม)
- **📗 ส่งออก Excel** — ดาวน์โหลดข้อมูลยอดขายเป็นไฟล์ Excel
- **ปิดหน้าต่าง** — ปิด

## 11. หลังบ้าน (Admin Panel)

เข้าได้จากปุ่ม **⚙️ จัดการหลังบ้าน** (แอดมิน) — เมนูด้านซ้ายมีดังนี้
ปุ่ม **กลับสู่หน้าร้าน** อยู่ล่างสุดของเมนูซ้าย

### 11.1 แดชบอร์ด
ภาพรวมยอดขายรวม, จำนวนออเดอร์, คิวที่รอ และธุรกรรมล่าสุด

### 11.2 จัดการเมนู
- **เพิ่มเมนูใหม่** / แก้ไข / ซ่อน / ลบ — ค้นหาเมนูได้ทั้งชื่อไทยและอังกฤษ
- ข้อมูลของเมนู:
  - **ชื่อ (ไทย / อังกฤษ)**, **รายละเอียด** — มีปุ่ม ✨ **แปลอัตโนมัติ**
  - **รูปภาพ** — อัปโหลดจากเครื่อง หรือวางลิงก์รูป
  - **หมวดหมู่หลัก** + **หมวดเพิ่มเติม** (เลือกได้หลายหมวด)
  - **ราคา** — ตั้งชื่อประเภทราคาได้ สูงสุด 5 ราคา (เช่น *ปกติ*, *พนักงาน*, *เดลิเวอรี่*)
    → ชื่อราคาเหล่านี้คือตัวเลือกใน **"ประเภทลูกค้า"** บนหน้าร้าน
    → ควรมีราคาชื่อ **"ปกติ"** ทุกเมนู
  - **เปิดใช้งาน (แสดงบนหน้าร้าน)** — เอาติ๊กออกเพื่อซ่อนเมนู (เช่น ของหมด)
  - **ส่งปริ้นไปที่เครื่อง** — เลือกเครื่องพิมพ์ของเมนูนี้
  - **เมนูที่เพิ่มอัตโนมัติเมื่อสั่ง (Bundled Items)** — ของแถมที่ใส่ให้อัตโนมัติ
  - **สูตรวัตถุดิบ (BOM)** — แสดงต้นทุน/จาน และกำไรขั้นต้น (แคชเชียร์ไม่เห็นต้นทุน)
- **ตัวเลือกตอนสั่ง (Popup)** — ตั้งได้ 6 ชุด ต่อเมนู แต่ละชุดกำหนด:
  - **ดึงเมนูจากหมวดหมู่** — ตัวเลือกมาจากเมนูในหมวดไหน
  - **เลือกรายการที่จะแสดง** (ไม่ติ๊กเลย = แสดงทุกเมนูในหมวด)
  - **บังคับเลือกอย่างน้อยกี่รายการ** (0 = ไม่บังคับ)
  - **จำกัดจำนวนสูงสุด** (0 = ไม่จำกัด) และ **max/รายการ**
  - **เลือกซ้ำได้** (ไม่ติ๊ก = แต่ละตัวเลือกเลือกได้ครั้งเดียว)
  - **ฟรี (ไม่บวกราคาเพิ่มในบิล)**
  - **แสดง ทานร้าน/ห่อกลับ**
- กด **บันทึกเมนู**

### 11.3 หมวดหมู่
- เพิ่ม / แก้ไขหมวดหมู่: **ชื่อไทย/อังกฤษ**, **Slug** (รหัสภาษาอังกฤษ เช่น `drinks`), **ไอคอน (อีโมจิ)**, **เปิด/ซ่อน**
- กด **บันทึกข้อมูล**

### 11.4 พนักงาน (เฉพาะแอดมิน)
- **เพิ่มพนักงาน**: กรอก **ชื่อสาขา (Branch)**, **ชื่อผู้ใช้**, **รหัสผ่าน**
- **ระดับสิทธิ์**: พนักงานทั่วไป / 💳 แคชเชียร์ / 👑 แอดมิน
- **สิทธิ์ชำระเงิน**: อนุญาต / ไม่อนุญาต
- กด **บันทึกทั้งหมด** → ขึ้น *"✅ บันทึกลง Google Sheet แล้ว"*
- ชื่อสาขาคือชื่อที่ขึ้นในหน้าเข้าสู่ระบบ และใช้เป็น **รหัสนำหน้าเลขบิล**

### 11.5 ส่วนลด
- **เพิ่มส่วนลด**: ตั้งชื่อ (เช่น *ส่วนลดสมาชิก, ลด Happy Hour*)
- **ประเภท**: ฿ บาท (ลดคงที่) หรือ % เปอร์เซ็นต์
- **หมวดหมู่ที่ใช้ได้** (ไม่เลือก = ทุกหมวด)
- กด **บันทึกส่วนลด** — ส่วนลดจะขึ้นให้เลือกในขั้นตอนชำระเงิน

### 11.6 ปริ้นเตอร์ (เฉพาะแอดมิน)
- เพิ่มเครื่องพิมพ์ได้ไม่จำกัด: **ชื่อ**, **IP Address**, **ประเภท** (ใบเสร็จ / ครัว / บาร์ / อื่นๆ)
- กด **ทดสอบ** เพื่อพิมพ์ทดสอบ → กด **บันทึกการตั้งค่า**
- ดูรายละเอียดในหัวข้อ [12. เครื่องพิมพ์ใบเสร็จ](#12-เครื่องพิมพ์ใบเสร็จ)

### 11.7 BOM / สูตรอาหาร (เฉพาะแอดมิน)
- **คลังวัตถุดิบ**: รหัส, ชื่อ, **หน่วยใช้** (ใช้ในสูตร), **หน่วยซื้อ** และอัตราแปลง (1 หน่วยซื้อ = กี่หน่วยใช้), ต้นทุน/หน่วยใช้, **สต็อกขั้นต่ำ**
- **BOM เมนู**: เลือกเมนูทางซ้าย → เพิ่มวัตถุดิบและปริมาณต่อจาน → เห็น **ต้นทุน/จาน** และ **กำไรขั้นต้น/จาน**
- กด **บันทึก BOM** แล้วกด **Sync ไปยัง GAS** เพื่อให้ระบบตัดสต็อกอัตโนมัติตอนขาย
- ปุ่ม **ดึงจาก GAS** — โหลดวัตถุดิบจากชีต "วัตถุดิบ"

### 11.8 สต็อกวัตถุดิบ
- ดูวัตถุดิบทั้งหมด, **มูลค่าสต็อครวม**, รายการ **ใกล้หมด/หมดแล้ว**
- กรองสถานะ: 🟢 ปกติ / 🟡 ใกล้หมด / 🔴 หมด
- **บันทึกรับวัตถุดิบ** (เมื่อซื้อของเข้า): เลือกวัตถุดิบ, จำนวน (หน่วยซื้อ), ราคา/หน่วยซื้อ, หมายเหตุ → บันทึก
  (ต้นทุนต่อหน่วยจะอัปเดตอัตโนมัติ)

### 11.9 ตั้งค่าร้าน (เฉพาะแอดมิน)
- **ค่าเซอร์วิสชาร์จ** — เปิด/ปิด และกำหนดอัตรา %
- **ภาษีมูลค่าเพิ่ม (VAT)** — เปิด/ปิด และกำหนดอัตรา %
- **QR รับเงิน** เลือกแบบ:
  - **K Shop (Dynamic QR) ⭐** — สร้างยอดเงินอัตโนมัติ (แนะนำ) อัปโหลดรูป QR ร้าน ระบบอ่าน Ref 1 / Ref 2 ให้
  - **พร้อมเพย์ทั่วไป** — กรอก **หมายเลขพร้อมเพย์**
  - **รูปภาพนิ่ง** — ใช้รูป QR แบบไม่มียอดเงิน
  - ตั้ง **ชื่อร้านค้า** และ **ชื่อบัญชี** ที่จะแสดงบนการ์ด QR
- **QR แยกตามสาขา**: เลือกสาขา แล้วตั้ง QR ของสาขานั้น (สาขาที่ไม่ได้ตั้ง จะใช้ QR กลาง)
- กด **บันทึกการตั้งค่า**

### 11.10 รายงาน (เฉพาะแอดมิน)
แท็บรายงาน: **สรุปประจำวัน**, **รายรับ-รายจ่าย**, **ยอดขายตามเมนู**, **ประวัติการขาย**, **ประวัติยกเลิก**, **รายงานปิดกะ**
เลือกช่วงวันที่ (วันนี้ / 7 วัน / 30 วัน / เดือนนี้) และกรองตามสาขาได้

### 11.11 หน้าจอห้องครัว / กูเกิลชีต
- **หน้าจอห้องครัว** — แสดงออเดอร์ที่รอทำ พร้อมเวลารอ มีปุ่ม **พิมพ์บิล / สำเร็จแล้ว / ยกเลิก**
- **กูเกิลชีต (ข้อมูล)** — เปิด Google Sheet ที่เก็บข้อมูล

## 12. เครื่องพิมพ์ใบเสร็จ

มี 2 วิธีพิมพ์:

### วิธีที่ 1: พิมพ์ผ่านเบราว์เซอร์ (ใช้บ่อยที่สุด)
ในหน้าชำระเงินสำเร็จ กด **🖨️ พิมพ์ใบเสร็จ** → หน้าต่างพิมพ์ขึ้น → เลือกเครื่องพิมพ์ใบเสร็จ 80mm → พิมพ์

### วิธีที่ 2: พิมพ์อัตโนมัติผ่าน Print Server (เครื่องพิมพ์ LAN)
1. เครื่องพิมพ์ต้องอยู่ **วงแลน (Wi-Fi/LAN) เดียวกัน** กับเครื่อง POS
2. ที่คอมพิวเตอร์ร้าน ดับเบิลคลิก **`start-printer.bat`** (เปิด Print Server) — **ห้ามปิดหน้าต่างสีดำ**
3. ตั้งค่า IP เครื่องพิมพ์ที่ หลังบ้าน → **ปริ้นเตอร์** → กด **ทดสอบ**

> ถ้าขึ้น *"ติดต่อ Print Server ไม่ได้"* = ยังไม่ได้เปิด `start-printer.bat` หรือหน้าต่างถูกปิดไป

## 13. กรณีอินเทอร์เน็ตหลุด / ข้อความแจ้งเตือน

ระบบมี **แถบแจ้งเตือนด้านบนจอ** (แตะเพื่อปิด):

| แถบ | ความหมาย | ต้องทำอะไร |
|---|---|---|
| 🔴 *"บันทึกบิล ... ขึ้นระบบไม่สำเร็จ! ข้อมูลถูกสำรองไว้ในเครื่องแล้ว"* | เน็ตหลุดตอนกดเสร็จสิ้น | **ห้ามล้างข้อมูลเบราว์เซอร์** เช็กอินเทอร์เน็ต ระบบจะส่งซ้ำให้อัตโนมัติ |
| 🟢 *"ส่งบิลที่ค้าง X รายการขึ้นระบบสำเร็จแล้ว"* | ส่งบิลที่ค้างสำเร็จ | ไม่ต้องทำอะไร |
| 🔴 *"ส่งบิลค้างได้ X รายการ เหลืออีก Y รายการ"* | ยังส่งไม่หมด | เช็กอินเทอร์เน็ต แล้วรีเฟรชหน้าเว็บ (ระบบลองส่งใหม่ตอนเปิดแอป) |
| 🔴 *"อยู่ในระบบครบ 8 ชั่วโมงแล้ว..."* | ล็อกเอาต์อัตโนมัติ | ล็อกอินใหม่ |

> 💡 ถ้าเน็ตหลุด ระบบยังแสดงเมนูจากข้อมูลที่จำไว้ในเครื่องได้ แต่ข้อมูลโต๊ะ/ยอดขายอาจไม่อัปเดต
> ⚠️ ห้ามกด "ล้างประวัติ/ล้างข้อมูลเว็บไซต์" ในเบราว์เซอร์ ถ้ายังมีบิลค้างส่ง

## 14. ขั้นตอนทำงานประจำวัน (Checklist)

### 🌅 เปิดร้าน
- [ ] เปิดเครื่อง POS และเชื่อมต่ออินเทอร์เน็ต
- [ ] (ถ้าใช้เครื่องพิมพ์ LAN) เปิด `start-printer.bat` ที่คอมร้าน
- [ ] เข้าสู่ระบบด้วยสาขาของตัวเอง
- [ ] กด 🔄 รีเฟรช ตรวจสอบเมนู/ราคาให้ถูกต้อง
- [ ] เมนูที่ของหมด → แจ้งแอดมิน/แคชเชียร์ปิด "เปิดใช้งาน" ในหลังบ้าน

### 🍽️ ระหว่างวัน
- [ ] เลือก **ประเภทลูกค้า** ให้ถูกก่อนสั่งทุกครั้ง
- [ ] ส่งรายการอาหารทุกครั้งหลังรับออเดอร์ (อย่าค้างไว้ในตะกร้า)
- [ ] ชำระเงินแล้วต้องกด **"เสร็จสิ้น"** ทุกครั้ง
- [ ] เงินโอน: แนบสลิปทุกครั้งเท่าที่ทำได้
- [ ] ของเสีย/ทำตก บันทึก **Waste** ทันที

### 🌙 ปิดร้าน
- [ ] ตรวจสอบหน้าสรุปบิล ว่าไม่มีโต๊ะค้างชำระ
- [ ] ตรวจสอบว่าไม่มีแถบแดง "บันทึกไม่สำเร็จ" ค้างอยู่
- [ ] เปิด **📊 สรุปยอดขายวันนี้** นับเงินสดในลิ้นชักเทียบกับยอด "เงินสด"
- [ ] กด **💾 รูปภาพ (PNG)** หรือ **ส่งออก Excel** ส่งรายงานให้ผู้จัดการ
- [ ] ออกจากระบบ

## 15. คำถามที่พบบ่อย / แก้ปัญหาเบื้องต้น

**Q: เมนูใหม่ / ราคาที่แก้ ไม่ขึ้นที่หน้าร้าน**
A: รอ 10 วินาที หรือกด 🔄 รีเฟรช — ถ้ายังไม่ขึ้น ตรวจสอบว่าเมนูติ๊ก "เปิดใช้งาน" และหมวดหมู่ไม่ได้ถูกซ่อน

**Q: ราคาเมนูไม่ตรง**
A: ตรวจสอบ **ประเภทลูกค้า** ด้านบนว่าเลือกถูกหรือไม่ (ถ้าเลือก "พนักงาน" ไว้ ราคาทุกเมนูจะเป็นราคาพนักงาน)

**Q: กดชำระเงินไม่ได้ (ปุ่มเทา)**
A: บัญชีนี้ถูกตั้ง "ไม่มีสิทธิ์ชำระ" — ให้แอดมินเปลี่ยนที่ หลังบ้าน → พนักงาน

**Q: สั่งผิดโต๊ะ**
A: ไปหน้าสรุปบิล → ติ๊กรายการที่ผิด → **ย้ายโต๊ะ / แยกโต๊ะ** ไปโต๊ะที่ถูกต้อง

**Q: สั่งผิดรายการ**
A: ในหน้าสรุปบิล กดไอคอน 🗑️ ข้างรายการนั้น แล้วสั่งใหม่

**Q: ปิดหน้าต่างชำระเงินไปก่อนกด "เสร็จสิ้น"**
A: บิลยังไม่ถูกบันทึกและรายการยังอยู่ที่โต๊ะ — เข้าสรุปบิลแล้วกดชำระเงินใหม่

**Q: QR โอนเงินไม่ขึ้น**
A: ตรวจสอบอินเทอร์เน็ต และให้แอดมินตรวจสอบการตั้งค่า QR ที่ หลังบ้าน → ตั้งค่าร้าน (รวมถึง QR ของสาขา)

**Q: เข้าสู่ระบบไม่ได้ / ไม่มีรายชื่อสาขา**
A: เช็กอินเทอร์เน็ต → กด "ลองเชื่อมต่อใหม่" ถ้ารหัสผ่านผิด ให้แอดมินตรวจสอบรหัสที่หน้า พนักงาน

**Q: พิมพ์ใบเสร็จไม่ออก**
A: (พิมพ์ผ่านเบราว์เซอร์) ตรวจสอบเครื่องพิมพ์ที่เลือกในหน้าต่างพิมพ์ / (เครื่องพิมพ์ LAN) ตรวจสอบว่าเปิด `start-printer.bat` อยู่ และเครื่องพิมพ์อยู่วงแลนเดียวกัน

## 16. ภาคผนวก: หน้าจอเสริม

หน้าจอต่อไปนี้มีอยู่ในระบบ แต่ **ยังไม่มีปุ่มกดเข้าจากหน้าร้าน** — เข้าได้โดยพิมพ์ต่อท้ายที่อยู่เว็บ:

| หน้าจอ | ที่อยู่ | ใช้ทำอะไร |
|---|---|---|
| ฝากเหล้า / เบิกเหล้า | `/liquor` | บันทึกลูกค้าฝากเหล้า/เบียร์ (ชื่อ, เบอร์โทร, ยี่ห้อ, จำนวนขวด), เบิกออก, ดูสต็อกคงเหลือและประวัติ |
| บิลค้าง | `/outstanding` | ดูรายการบิลค้างชำระ (ชื่อลูกค้า, เบอร์โทร, ยอด, รายการ) |
| หน้าจอห้องครัว | `/kitchen` | ดูออเดอร์รอทำ (แอดมินเข้าจากเมนูหลังบ้านได้) |

> หมายเหตุ: ปุ่ม "กลับ" ของหน้าฝากเหล้าและหน้าบิลค้างยังพาไปหน้าที่ไม่มีอยู่ — ให้กดเข้า `/index` เพื่อกลับหน้าสั่งอาหาร
